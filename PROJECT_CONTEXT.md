# Project Context: Bodycam Bulk Footages & Automation

## 1. Project Mission & Scope
This project manages end-to-end research, harvesting, verification, packaging, and video production workflow documentation for raw, unwatermarked police bodycam footages.

Key operations include:
- Sourcing direct raw police records, FOIA portals, court evidence submissions, and city archives (avoiding media/YouTube watermarks).
- Packaging verified multi-angle case bundles into Google Drive for active clients.
- Auditing client Google Sheets and maintaining real-time manifests.
- Managing task state on the **Nikhil** Trello board.
- Documenting production workflows and editing styles for YouTube (long-form) and Snapchat (vertical short-form).

## 4. Operational Guidelines & Rules

1. **Trello Etiquette**:
   - Comments must be short, clean, and direct.
   - **Never mention anyone** (`@someone`).
   - Only move cards or post comments after user review/confirmation.
2. **Writing & Typography Style**:
   - British English spelling (`finalisation`, `prioritise`, `summarise`).
   - Clean formatting, plain text / Arial default font in Google Docs, 0.5pt bordered tables.
   - **No long hyphens / em-dashes** (use short hyphens `-` or restructure).
3. **Token Efficiency**:
   - Always adhere to `.agents/rules/token-optimization.md`.
   - Use scripts for batch operations rather than emitting repetitive commands.
   - Restrict tool inspection outputs to under 50 lines.
4. **Footage Standards**:
   - Prioritize unwatermarked, multi-angle raw bodycams, dashcams, and interrogation videos from official department portals, S3 buckets, and city archives.
   - Avoid low-resolution screen-recordings and branded YouTuber/media re-uploads whenever possible.
